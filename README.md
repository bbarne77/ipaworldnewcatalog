# iPAWORLD Catalog

**iPAWORLD — удобный каталог приложений для iPhone.** Находите приложения, банки и игры в одном месте, пользуйтесь быстрым поиском и открывайте каталог с экрана «Домой». Интерфейс работает в тёмной теме.

## Публикация
Загрузите файлы из этой папки в корень репозитория `bbarne77/ipaworldnewcatalog`. GitHub Pages публикует сайт по адресу https://bbarne77.github.io/ipaworldnewcatalog/.

## Профиль установки
Кнопка установки профиля ведёт на Cloudflare Pages: https://ipaworld-profile.pages.dev/ipaworld.mobileconfig. Профиль добавляет Web Clip — ярлык каталога на экран «Домой» с полноэкранным запуском. Он не устанавливает IPA-файлы и не управляет VPN.
